# 國字樂園 · Guozi Playground

給國小一年級小朋友的國字學習網站，接在 [注音樂園](https://github.com/mikabeneton33-hub/zhuyin-playground) 之後：注音學完，開始認字、寫字、讀短文。純靜態、免安裝、免登入，進度只存在自己的裝置。

> **目前狀態：骨架階段。** 站內的生字與課次是 10 個常用字的**示範資料**（`js/data.js` 的 `BOOK.placeholder = true`，畫面上會顯示「示範資料」提示），用來把整條流程跑通。南一版國語第一冊的正式課次與生字表尚未匯入。

## 現有功能

| 分頁 | 內容 |
|---|---|
| 生字 | 田字格生字卡：楷體大字、注音、部首、筆畫、造詞、例句、插圖，詞和句都可點讀。 |
| 課程 | 依課次推進，過關解鎖下一課；每課有描寫、8 題闖關（聽音選字＋看字選音）、自編短文與理解題。結果用「優／良／可」印章表示。 |
| 遊戲 | 聽音選字、看字選音、寫寫看（田字格描寫）、字音配對（翻牌），範圍可選到哪一課。 |
| 聽寫 | 給家長：選範圍、題數、速度，站台唸詞語，孩子寫在紙上，最後對答案打勾。 |
| 我的 | 星星、連續天數、今日任務、家長設定。 |

## 設計

視覺語彙取自一年級的方格簿：紙白底、墨藍字、朱紅批改，核心物件是田字格；完成時蓋紅圈、蓋印章，不放彩帶和卡通貼紙。生字用楷體（課本和作業簿的字形），字型隨站自帶，離線也一樣。注音照課本直排在字的右側，聲調在最後一個符號右邊、輕聲點在最上面；只替還沒學過的字標注音。所有可點元素 44px 以上、可鍵盤操作、支援 `prefers-reduced-motion`。

## 內容原則

- **課次結構與生字表**：只收課程結構的事實資訊（課名、頁碼、各課生字），不收課文全文、不收出版社插圖。
- **詞語、例句、短文、題目**：全部自編，且只用「到該課為止學過的字」；還沒學的字用 `字{ㄗˋ}` 標注音。`node tools/check-data.mjs` 會檢查：未學過的字沒標注音、注音格式、詞語音節數、插圖是否存在、真人錄音覆蓋率。
- **讀音**：依教育部《重編國語辭典修訂本》。

## 資料與工具

```
js/data.js          課次、生字、造詞、例句、短文（標注音寫法見檔頭說明）
js/ruby.js          `字{注音}` 標注音解析與渲染
tools/check-data.mjs        資料檢查（有錯 exit 1）
tools/build-voice-map.mjs   從注音樂園挑出用得到的真人錄音，複製 mp3 並重寫 js/voice_map.js
tools/build-font.py         把霞鶩文楷 TC 縮成本站用到的字（fonts/gzkai.woff2）
```

```bash
node tools/check-data.mjs
node tools/build-voice-map.mjs ../zhuyin-playground   # 加了新字詞之後
python3 tools/build-font.py LXGWWenKaiTC-Regular.ttf  # 加了新字之後（需要 pip install fonttools brotli）
python3 -m http.server 8000                           # 本機預覽
```

## 技術

單純 HTML / CSS / JavaScript（ES modules），沒有框架、沒有建置步驟。PWA（manifest + service worker）。發音有「真人／合成」兩種模式：真人錄音來自教育部《國語辭典簡編本》，沒有錄音的字詞自動改用瀏覽器合成語音。

## 還沒做（依序）

1. 正式字表：南一第一冊發下來之前，改用教育部《國小學童常用字詞調查報告書》表二十五（部編本《國語》第 1、2 冊收字與字頻）選字、自己排課次。該資料庫需向教育部申請授權（非商業教育用途），核准前不收錄。
2. 部件拼字（需要字形拆解資料）；詞語與句子練習：量詞、相反詞、排句子、標點。
3. 筆順：描寫改為判斷筆畫順序。資料來源與教育部標準筆順的核對方式待確認，逐字核對後才上線。
